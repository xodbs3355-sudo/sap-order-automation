# 변경 이력 (CHANGELOG)

이 파일은 프로그램 버전별 주요 변경사항을 **최신순**으로 기록합니다.

**버전 규칙 (유의적 버전 · 주.부.수정):**
- 주(Major) `X.0.0` : 기존과 크게 달라지는 변경 (권역/대상 확장, 화면 전면 개편 등)
- 부(Minor) `1.X.0` : 기능 추가 (기존 사용법은 그대로 유지)
- 수정(Patch) `1.0.X` : 버그 수정 · 문구/위치 등 소소한 손질
- 윗자리를 올리면 아랫자리는 0으로 리셋 (예: `1.0.3` + 기능추가 → `1.1.0`)
- 버전은 **의미 있는 변경 단위로** 올린다. 버전 값은 `app/config/settings.json`의 `version`/`version_date`에서 관리.

## [1.1.0] - 2026-11-14
### 추가
- 시작 대기창(스켈레톤): 실행 직후 본 화면과 같은 배치의 회색 틀 + "화면을 준비하고 있습니다" 안내·경과 초·왕복 막대를 표시하고, 본 화면이 다 그려지면 닫힘. 화면 엔진(WebView2)과 무관한 별도 창(tkinter)이라 엔진 부팅을 기다리지 않음.
  - 위치·크기: 본 창 내용 영역과 같은 자리. 본 창이 뜨는 순간 실제 좌표로 한 번만 맞춤(본 창은 건드리지 않음). 대기창은 옮길 수 없음.
  - 안전장치: 프로그램이 오류로 끝나도 대기창이 같이 닫힘 / 화면 로딩 완료 8초 후 · 최대 180초 후 자동 닫힘.
  - 글꼴: 대기창 글자만 담은 작은 나눔고딕·지마켓산스 TTF를 프로그램 안에서만 등록해 사용(설치 안 함). 실패 시 맑은 고딕으로 표시.
- 시작 시간 측정 로그 추가: 파이썬 켜지는 시간 · 대기창 표시 · 본 창 표시(창 틀) · 화면(HTML) 로딩 완료 · 대기창 위치 차이 · 대기창 글꼴.

## [1.0.3] - 2026-11-12
### 변경
- 첫 실행 속도 개선: 화면 연결용 `Api` 객체가 창(window) 참조를 `_window`(밑줄 이름)로 보관하도록 변경. pywebview 가 시작 시 노출 함수를 찾으며 창 내부(.NET 창 부품·크기/위치 조회)까지 훑던 작업을 건너뛰게 함. 화면 기능은 동일.
